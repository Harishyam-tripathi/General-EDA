# 🔍 General Exploratory Data Analysis (EDA)

This project performs a **General Exploratory Data Analysis** on a dataset to uncover trends, patterns, and anomalies. It includes **data cleaning, statistical analysis, and visualizations** for better understanding of the data.

---

## 📂 Dataset
- **File:** `global_superstore.csv`  
- **Columns Examples:**  
  - `Sales` → Sales amount  
  - `Profit` → Profit earned  
  - `Region` → Geographical region  
  - `Category` → Product category  
  - Other relevant features depending on dataset  

---

## ⚙️ Tech Stack
- Python 3.x  
- pandas, numpy  
- matplotlib, seaborn  

---

## 🚀 Steps Performed

1. **Data Cleaning**  
   - Handled missing values (mean/median/mode)  
   - Removed duplicates  
   - Detected and handled outliers using IQR or Z-score  

2. **Statistical Analysis**  
   - Calculated mean, median, standard deviation, variance  
   - Computed correlations between features  

3. **Visualizations**  
   - **Histograms** → Distribution of numerical data  
   - **Boxplots** → Detect outliers  
   - **Heatmaps** → Visualize correlations  
   - Other relevant plots to explore patterns  

---

## 📊 Example Insights
- Certain regions contribute more to total sales  
- Profit margins vary significantly by product category  
- Outliers in sales/profit highlight unusual transactions
